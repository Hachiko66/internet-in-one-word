The whole internet in one word: **Lurking**.

Ninety percent of the internet never posts, never comments, never likes — they just watch. Billions of silent readers in one loud room: the internet isn't a conversation, it's everybody lurking, all day, in every tab. It is funny on its own, true of the entire internet rather than any one site, and not the first word anyone reaches for. The program writes the word to the output directory after validating it against the gate; run it with `--reason` to see the pitch.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
